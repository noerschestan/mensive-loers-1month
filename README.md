# Mensive Loers — 1 Month Anniversary (Starter)

Starter React + Vite project built with:
- React
- Tailwind CSS
- Framer Motion (animations)
- Lucide Icons

Features:
- Hero with CTA
- Envelope that opens to reveal handwritten letter
- Polaroid gallery
- Scrapbook-style reasons grid
- Timeline
- Playlist + music toggle
- Interactive message card + animasi hati

Setup:
1. Install deps:
   npm install
2. Run dev server:
   npm run dev
3. Buka di browser: http://localhost:5173

Catatan:
- Ganti file di `public/assets/` dengan foto/foto pasangan dan audio (`our-song.mp3`, `cover.svg`).
- Konfigurasi pasangan, warna, dan path assets ada di `src/data/siteConfig.js`.
- Sesuaikan font di `index.html` jika ingin font handwriting lain.
